⑨ 🔥 主应用样式消失复现点 🔥

下面这个按钮的样式不是写死在 styles.scss / component scss 里的，而是组件 ngAfterViewInit 时 JS 动态 document.head.appendChild(<style>) 注进去的。 很多第三方库（包括 ng-devui 的 Modal / Tooltip）就是这么做的。
