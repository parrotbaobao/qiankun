# 协作方式与学习进度

## 对接手 AI 的要求

- 中文、紧凑、一次一个问题。单行代码用行内代码，避免为变量单独开代码块；多行执行逻辑才使用代码块。
- 用户说 next/下一题时，先核对约定清单题号，不自行发明下一题。已经发生过脱离清单、浪费时间的问题。
- 讲源码先读实际文件与调用点。确认是否真的调用，再解释，不让用户学习未使用接口。
- 用户基础概念需要细讲：每一步输入、输出、谁调用、何时执行、函数何时保存何时调用；少用抽象术语，术语第一次出现就解释。
- 不把回调都叫异步，不把状态管理只说成动画，不以“企业工程化”添加无实际用途防护。
- 用户明确要求的低风险改动直接做；保留无关工作树数据，不擅自push。git提交只stage本次文件。
- 用户语音有误识别，结合上下文理解：微前端、子应用、qiankun、AbortController、RxJS、Prompt、onopen等；有歧义再确认。
- 完整项目口述练习用户要求放到最后，先整理材料，不反复要求现场回答。小段口述有意愿再练。
