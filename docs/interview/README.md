## 推荐阅读顺序

1. [经历与事实边界](./experience.md)：个人背景、三个项目、指标口径、历史修正。
2. [技术讲述与常见追问](./technical-preparation.md)：可用口述框架、具体技术流程。
3. [协作方式与下一步](./learning-progress.md)：如何讲解、当前进度、后续练习。

这些文件应先于旧笔记阅读。若与更早聊天或示例冲突，以用户最新明确纠正为准；仍有疑问时标为待核实，不猜成事实。

## 证据等级

- **用户已确认**：用户明确回忆或确认的历史行为；可以作为当前面试讲述依据，但不等于已审计源码。
- **最新简历表述**：用户提供的最后版截图中的表述；不自动证明每一个实现细节。
- **当前本地实现**：本仓库可检验代码，部分为面试学习期间重构；不得倒推为历史公司原始代码。
- **原理／方案／设想**：帮助理解的示例或后续优化方向，不能写成已交付成果。
- **待核实**：证据不足，不能补成确定事实。

本仓库是本地演示和学习工程，不是用户原公司的完整生产源码。公开产品文档、官网页面和 Astro 源码只证明对应产品或库的能力，不证明个人职责。未收录手机号、邮箱、凭据及登录信息。
